# 谷雨 · 开发测试

改完 `js/` 里的文件后跑一遍，确认没弄坏别的地方。

## 最省事：双击 `自测.bat`

第一次会自动装一下测试工具（要联网，只装一次），之后每次双击就把下面所有测试跑一遍，
最后告诉你哪组过了、哪组没过，结果也存进 `自测结果.txt`。
**用的是你电脑上的 Edge**，不用另外下载浏览器；全程不联网、不动你的存档。

命令行也行（在项目根目录，就是 index.html 那一层）：

```bash
node _开发测试\run-all.mjs              # 全部跑一遍（15 组，大约 3 分钟）
node _开发测试\run-all.mjs leak card    # 只跑名字里带这几个词的
```

## 📌 发新版本只改一个数

`index.html` 最上面的 `var GY_VERSION = 181;`——改这一个数就行。
所有 js、style.css、离线缓存（service-worker）、设置页最底下显示的版本号全都跟着它走。
加新的 js 模块：往 index.html 底下那个 `gyLoad([...])` 列表里加一行，再往 service-worker.js 的清单里加一行。

9/24 起几个超大的文件拆成了两三段（01→01/01b/01c，04/05/06/08/10/13 各多一个 b 段）。
拆开的几段共用同一个全局作用域，只是分开放；`index.html` 里的加载顺序不能换。

## 几个测试各自盯着什么

- **input-test** — 「输入框打不了字」的回归防线。它不看代码，直接量输入框在不在视口里、
  点它的坐标命中的是不是它本人、键盘敲进去的字有没有进去。短聊天/长聊天/角色刚发完消息/
  刚删过消息/右键菜单开过又关/导入备份之后/手机尺寸，七种情形各测一遍。

- **freeze-test** — 量的是「主线程被占住了多久」。它每 10ms 打一个点，看最长一次多久没打上。
  超过 300ms 用户就能感觉到卡、键盘输入会丢。修 saveAllData 之前这个数是 1700ms，
  修完是 100ms 上下。以后往聊天渲染路径里加东西，跑一下这个别让它涨回去。

- **leak-test** — 防止 AI 返回的原始 JSON 信封和思维链漏进聊天气泡。既测新消息（写入侧），
  也测已经存坏在历史里的旧消息（渲染侧兜底）。同时测流式开关是真的改到了请求体。

- **adaptive-test** — 守住"这个网站不是只给一个人用的"。检查源码里没有把具体人名当默认值、
  用户改名之后提示词跟着变、名字空着也不会拼出断句；以及所有**能在设置里自定义的时间**
  （休息时间段、回信/日记等待时长）在提示词里都是按实际值算出来的，不是写死的钟点。
  以后再往提示词里写时间之前，先想一下这个时间用户能不能改——能改就不能写死。

- **scrollbar-test** — 滚动条平时透明、鼠标移上去才浮现。注意它启动浏览器时特意关掉了
  `--hide-scrollbars`：无头浏览器默认把滚动条整个藏掉，不关这个开关，这个测试**永远是绿的**
  （因为压根没有滚动条可测）。里面还锁了两条写法：不能用 `:hover::-webkit-scrollbar-thumb`
  （Chromium 里画不出来），`scrollbar-color` 必须圈在 `@supports` 里（它是继承属性，
  裸写会让整套 `::-webkit-scrollbar` 样式全部失效）。

- **binding-test** — 扫全部内联事件（`onclick` / `onchange` / …），确认它们调用的函数**真的存在**。
  绑了个不存在的函数，点下去只在控制台报一句 "xxx is not defined"，界面上毫无反应，
  自己点是发现不了的。同时会查有没有人又用回原生 `prompt()` —— **Electron 不支持它**，
  一调就抛异常，表现同样是"点了没反应"。

- **relationship-test** — 守住"角色跟用户有关系时别变成不活人"。里面有一组关键对照：
  **两个角色人设一模一样（都写着沉默寡言/话很少），区别只在于有没有跟用户建立关系**。
  有关系的那个不能被 `isCoolTowardUser` 锁进"只能点赞"，没关系的那个必须照旧走高冷路线。
  以后要是有人把这个判断改回只看人设关键词，这条会红。

  还有一组是拿**九种关系标签**（情侣/敌对/宿敌/上司下属/债主/前任/师徒/一面之缘/自己编的）
  轮着跑一遍：每种都得能正常生成，而且措辞里**不许出现任何预设"关系亲近"的说法**。
  关系标签是用户自己能新建的，所以这段提示词既不能只为亲密关系写，
  代码里也不能按标签关键词分支——自定义标签一来就全废了。

- **stream-group-test** — 守两件新功能。
  **聊天的流式**跟续写的流式不是一回事：聊天要求模型返回一整段 `{"replies":[...]}` 的JSON，
  半截JSON贴进气泡就是乱码，所以聊天做不到逐字，只能**按气泡**——数组里哪条写完了先发哪条。
  干这件事的是 `extractStreamingReplies`，它的铁律是**宁可少捞一条晚点补上，也绝不能把
  半截货当成完整回复发出去**（消息发出去是收不回来的）。测试里专门喂了各种半截输入：
  对象没闭合、文字里带花括号和转义引号、思维链拼在最前面、压根不是JSON——
  只要有一点不确定就必须返回空，交给流式结束后那次完整解析兜底。
  另外还锁了一条：开流式和关流式最终发出来的气泡内容必须**一模一样**，
  开关只该影响"什么时候看到"，不该影响"看到什么"。

  **群聊转私聊**是角色自己决定的：它可以给其中一条回复加 `[MOVETOCHAT]` 前缀，
  这条就进1v1私聊、不进群。测试盯死三件事：转私聊那条不能漏进群聊记录、
  同一批里没带标记的照常进群、以及**任何情况下 "[MOVETOCHAT]" 都不能原样出现在用户眼前**——
  开关关掉时角色要是自己写了标记（预设/角色卡里教过），也只是把标记抹掉当普通群消息发。

  还有一条容易写坏的：**私聊不能占群聊的队**。真人是一边在群里接话、一边私戳你，
  两个窗口各按各的节奏；如果代码里 await 了私聊那条，群聊就会卡在那儿等它，
  变成"发完私聊才轮到群里"，一眼假。测试里专门把私聊那条排在群聊那条**前面**，
  然后掐着时间看：群里那句已经出来了，私聊那句还在路上（第一条私聊会多等
  1.5~4 秒，模拟真人切窗口的时间）。以后要是有人把那个 continue 改成 await，这条会红。

- **save-preset-test** — 增量保存：大图单独存、主存档只剩文字；图没变再存不多东西；重开后图原样回来；
  换图后旧图被清理、还在用的留着；老格式存档照样读；关页面那一刻有新图就整份存；图库丢图时置空。
  一键配置：省钱/推荐/全都要只动"后台自动花钱"的开关、换前列出改动、能撤销；我的配置：存（含小功能开关）、
  换回、跟着存档走、能删。用的是真的 IndexedDB（无头浏览器全新空白，不碰你的存档）。

- **peer-life-test** — 角色之间自己来往：只找关系网上的人（不认识的一次调用都不花）、提示词带两个方向的关系；
  私聊/写信/送东西/评论推文/打电话/朋友圈/转账各走一遍，两边手机里视角正确，信件/通话 app 出现在桌面上；
  「Ta们在做什么」页有控制栏。时间管理大师：自主模式能做的每件事都有卡，一次调用问完习惯，
  不定时重问（做完那件事才顺便定下一次）、不拦着（做得成的都摆上桌）、一次可以做好几件、
  等会儿再做的进队列到点再做、没有时间上下限；身上发生的事（别人找 TA、推文底下有人说话、今天是 TA 的日子……）会记下并让 TA 很快想想怎么反应；关掉小剧场后相关卡片消失、后台不动；重开记录还在。

- **life-dice-test** — 生活里的意外：出门在外比在家更容易碰上事、只是概率不是必然；提示词带此刻的日程和认识的人；
  碰上的事变成 TA 身上的事、进 prompt、不重复同一类；碰上认识的人两边都记下，不认识的不算；开关关着后台不碰；
  自主角色不给挡位（自己的节奏）、默认模式角色由你调挡（默认关，调了才会触发）；今天面板里能看到、能手动触发；右栏内容比屏幕高时能上下滑、滚轮滚得动；重开还在。

- **more-acts-test** — 自主模式接上各个小功能：约看电影/读书/玩游戏、转账红包、点外卖、商城买东西/上架、发照片、
  自己听歌看剧看书打游戏都在动作表里；对应功能没开就不出现；时间管理大师分「冲着你的 / 跟别人的 / 自己的日子」；
  真的做得成（邀请卡发出去、状态变了）；给自己点外卖不往你们的聊天里插消息。

- **today-mobile-test** — 手机上的「今天」：开着时底栏第二个按钮变日历，点进去是今天面板（话题收起、顶栏写「今天」），
  时间管理大师和随机事件都在，能往下滑、时间卡点得开且不超出屏幕；关掉后全部还原。

- **online-notify-test** — 在线找资源：iTunes 试听（JSONP）、档案馆完整音频/影片（先查文件清单拿直链）、维基文库古籍，
  能放进音乐盒/片库/书架；第二批动作（转发、影评、改日程、改签名、刷手机、分享歌、拉群通话）真的做得成；
  每件事进通知且带跳转，点通知/弹窗能跳到对应地方；本来就会弹的不重复弹。外网请求全部拦成假响应。

- **peek-bio-test** — 没被允许看的日记：TA 按人设决定翻不翻，翻了留痕迹、日记页能看到、通知不说是谁、TA 记得（进 prompt）、
  时间卡不暴露；允许/邀请的不算偷翻。过往签名：自己改、编辑页改都记，主页能点开看。论坛/匿名区回帖、自己发朋友圈。

- **features-0923-test** — 9 月 23 日那一批：版本号只改一处、思维链收纳（带标签的、JSON 前面没标签的）、
  聊天状态栏（写在 JSON 字段里也能摘、默认收起、换行还原）、卡片手机（发给你的变真消息、跟别人的收进手机、
  聊天里只留小卡）、TA 定（总开关 + 自主模式才自动、字数规定改写）、今天面板、全部开关只剩两样、
  推文图片菜单、角色卡自带正则绑到角色身上、重复导入提醒、聊天里的卡片小界面。
