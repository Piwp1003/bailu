# 白露 桌面版 · 打包成 exe

把白露打包成一个免安装的 `白露.exe`，双击就能用，别人电脑上不需要装 Chrome、不需要装任何东西。

---

## 怎么打包

**这个「桌面版」文件夹必须放在白露源码目录里**（跟 `index.html` 同级的下一层）：

```
克劳德神了\
├─ index.html
├─ style.css
├─ js\
├─ icons\
└─ 桌面版\          ← 就是这个文件夹
   ├─ 一键打包exe.bat
   ├─ 先试跑一下.bat
   ├─ 打不开时点我.bat
   ├─ tasks.js
   ├─ main.js
   ├─ sync.js
   ├─ package.json
   ├─ build\icon.ico
   └─ vendor\
```

然后：

1. 装 [Node.js](https://nodejs.org)（LTS 版，一路下一步）
2. 双击 **`一键打包exe.bat`**
3. 等几分钟，产物在 `桌面版\dist\白露.exe`

第一次要下约 100MB 的浏览器内核，脚本里已经把下载源切到国内镜像了。之后再打包就快了。

> 想先看看效果不打包 → 双击 `先试跑一下.bat`，直接用 Electron 跑，改完代码重跑几秒就出来。

改完白露源码后重新双击 `一键打包exe.bat` 就行，`sync.js` 会自动把最新代码同步进去。

## ⚠️ 存档不会自动搬过来

这是最容易踩的坑。

浏览器里的白露和 exe 版的白露，数据存在**两个完全不同的地方**，互相看不见。直接打开 exe 会是一个空白的新号。

搬家步骤：

1. 先用你**现在的方式**打开白露（浏览器 / 原来那个 bat）
2. 设置 → **导出数据**，存一个 json 出来
3. 打开 `白露.exe`
4. 设置 → **导入数据**，选刚才那个 json

**打包之前先把这一步做了**，别等用了几天新版才想起来老存档还在浏览器里。

## 存档放在哪

exe 第一次运行时，会在**它自己旁边**建一个 `BailuData` 文件夹，所有数据都在里面。

```
随便哪个文件夹\
├─ 白露.exe
└─ BailuData\          ← 你的全部数据
```

这么做的好处：整个文件夹拷到 U 盘/另一台电脑，存档跟着走。

几个注意的点：

- **别把 exe 单独拷走**，`BailuData` 要跟着一起
- **别放在 `C:\Program Files` 里** —— 那儿默认不让普通用户写文件。真放进去了程序会自动退回 `%APPDATA%`，能用，但就不"便携"了
- 文件夹名用英文是有意的：中文路径在某些环境下会让浏览器内核的数据库首次打开失败，表现是第一次保存弹「硬盘空间可能已满」
- 想手动备份：应用菜单 **文件 → 打开存档所在文件夹**

## 跟原来那个 bat 比，变了什么

原来的 `启动白露(桌面模式).bat` 是拿 `--app` 参数拉起系统里的 Chrome/Edge 打开 `file://`。exe 版解决了它的三个问题：

| | 旧的 bat | exe 版 |
|---|---|---|
| 依赖 | 用户必须装 Chrome 或 Edge | 内核跟着 exe 走，什么都不用装 |
| 存档位置 | `%TEMP%\guyu_app_profile` —— **清理临时文件就没了** | exe 旁边的 `BailuData`，跟着走 |
| 断网 | localforage / mammoth 从 cdnjs 拉，断网打不开 | 两个库已打进包里，断网正常用 |
| 渲染差异 | 取决于用户装的是哪个版本的浏览器 | 所有人一致 |

窗口大小和位置也会记住，下次打开还是上次那样。

## 关于「关掉了同源策略」

`main.js` 里设了 `webSecurity: false`。这不是偷懒——白露要直接 fetch 各家 AI 接口（包括各种中转），页面本身是 `file://` 起源，开着同源策略这些请求会被浏览器拦掉。你原来那个 bat 用 `--disable-web-security` 也是同一个道理，只是现在挪进了程序内部。

代价：页面里跑的脚本理论上能读本机文件。所以——

**「设置 → 允许执行注入脚本」这个开关保持默认关闭，别一边开着它一边导入来路不明的角色卡。**

渲染进程本身没给 Node 权限（`nodeIntegration: false`），所以就算有恶意脚本跑起来，也拿不到文件系统 API，风险面比听起来小。

## 可能遇到的情况

**杀毒软件报毒 / SmartScreen 拦截**
未签名的 exe 都会这样，跟内容无关。点「更多信息 → 仍要运行」即可。想彻底解决要买代码签名证书（一年几百到几千不等），个人用一般没必要。

**exe 有 100 多 MB**
Chromium 内核就这么大，Electron 应用都是这个量级。开了最大压缩了。真想要 5MB 的 exe 得换 Tauri 方案，但那个要装 Rust 工具链、且依赖用户系统里的 WebView2。

**打包时卡在下载**
多半是 NSIS 工具没从 GitHub 拉下来。重新双击 `一键打包exe.bat` 再试一次，脚本已经配了国内镜像；实在不行挂个梯子。

**打包报错说找不到 index.html**
`桌面版` 文件夹的位置不对，它必须在白露源码目录里面。

**打包完了，但 `dist` 里只有 `win-unpacked` 文件夹，没有 `白露.exe`**

打了一半。应用本体已经生成好了，只是最后「压成单个 exe」那步失败了——
那步要用 NSIS 工具，需要联网下载。

- **`dist\win-unpacked\白露.exe` 现在就能双击玩**，功能跟单文件版完全一样，
  只是分享时要把整个 `win-unpacked` 文件夹一起打包（用 7-Zip，别用 Windows 右键压缩）
- 想要单文件版：重新双击一次 `一键打包exe.bat`。脚本已经把下载源切到国内镜像了，
  多试一次经常就过；还不行就挂梯子

**打包成功了，但 exe 双击闪一下就没了**

双击 **`打不开时点我.bat`**。它会自动排掉最常见的原因，并把启动日志读出来。

exe 从进程一起来就往它旁边的 `启动日志.txt` 里记里程碑，所以闪退不是无迹可寻的。
按日志停在哪一步判断：

| 日志最后停在 | 说明 | 怎么办 |
|---|---|---|
| `已有另一个白露实例在运行` | 后台有残留进程，单实例锁让新的直接退出 | 诊断脚本会自动结束它，之后再双击 exe |
| `加载页面` 之后没有 `页面加载完成` | `app` 文件夹没打进 exe | 重新打包一次 |
| `!!! 崩溃于 ...` | 主进程异常 | 日志里有完整堆栈，直接看那段 |
| 日志根本没生成 | 进程压根没起来 | 八成被杀毒软件拦了，去拦截记录里加白名单 |

第一种最常见：上一次异常退出后进程挂在后台，之后每次双击都是闪一下就没。
任务管理器里搜「白露」，有就结束掉。

## 为什么 .bat 里一个中文都没有

cmd.exe 是按字节流解析批处理文件的。文件里只要出现中文（UTF-8 多字节），读取指针就可能串位，
把后面的命令从中间劈开——典型症状是报「'BINARIES_MIRROR' 不是内部或外部命令」这种
把一行 `set` 劈成两半的错，`chcp 65001` 也救不了，因为串位发生在解析阶段。

所以两个 `.bat` 都保持纯 ASCII，只当一层薄壳（切码页 → 找 Node → 调 `tasks.js`），
所有中文提示和实际逻辑都在 `tasks.js` 里，由 Node 输出，不受这个限制。

改这两个 bat 的时候，别往里加中文。要改提示文案就改 `tasks.js`。

## 想改的话

- **打包流程、提示文案** → `tasks.js`
- **窗口默认大小、标题、菜单** → `main.js`
- **哪些文件打进 exe** → `sync.js` 顶上的 `FILES` / `DIRS`
- **图标** → 换掉 `build\icon.ico`（256×256 的 ico）
- **exe 文件名、版本号** → `package.json` 的 `portable.artifactName` 和 `version`
- **想出安装包版本** → `package.json` 里 `win.target` 从 `portable` 改成 `nsis`

```
node_modules\.bin\electron _smoke.js
```

结果写在 `_smoke.log`，顺便会截一张 `_smoke-shot.png`。改了 `main.js` 或 `sync.js` 之后跑一下比较放心。
