# 白露

谷雨的字卡版。功能和谷雨一样（聊天、推文、信、日记、论坛、匿名区、朋友圈、电话、自主模式、小手机、微信模式……），
区别只有一个：**不接任何 API**。角色说的每一句话，都从你上传的字卡里按概率随机挑出来、拼起来。

## 怎么用
1. 双击 `index.html`（或 `启动白露(桌面模式).bat`）打开。
2. 设置 → **🃏 字卡库**：上传 / 粘贴字卡，也可以一键「从聊天记录、推文、信件里收集 TA 说过的话」。
3. 没导入字卡之前会先用一套示例字卡，导入第一批自己的字卡后示例会自动收起（字卡库里能放回来）。

## 字卡怎么写（txt）
一行一张字卡。用 `#` 开头的行给下面几行贴标签：

```
#类型:聊天 角色:霍樊
你等下冻的话，记得叫我
以后有事先找我，听到没
#类型:信
见字如面，{user}。
#推文
今天的风有点温柔。
```

- 类型：聊天 推文 评论 信 日记 论坛 匿名 朋友圈 电话 状态 标题 旁白 拍一拍 表情 格言 开场 通用
  - 拍一拍：TA 拍你时后半句（比如「的脑袋」）；表情：夹在话里的颜文字/emoji；格言：聊天顶上那一句；开场：打开时的动画，写成「主标题|副标题」
- 分组：字卡库里可以建分组（带颜色），整组停用/启用；json 里写 "分组":"甜" 也行
- 别的字卡软件导出的整包（customReplies / customPokes / customStatuses / customMottos / customIntros / customEmojis + 分组）可以直接导进来
- 导入时选「追加」（重复的跳过）或「覆盖」（整个库换成这一批）；还有一键去重
- 角色不写 = 谁都能用；写了就只有这个人会用
- 占位符：`{user}` 你的名字、`{char}` 说话的人、`{time}` 现在几点、`{date}` 今天日期
- 也支持 json（`["一句","两句"]` 或 `[{"text":"…","类型":"聊天","角色":"霍樊"}]`）和 csv（三列：内容,类型,角色）

- 条件：一行开头写 `{if 晚上}`，或标签行写 `条件:晚上|深夜`，这张卡只在满足时用。可写：凌晨 早上 上午 中午 下午 傍晚 晚上 深夜 白天、`22点-2点`、周末 工作日 周五、春天…冬天、12月、2月14日、`心情:开心`（TA 今天手账里的心情）、`我心情:累`（你自己记的）、`不是周末`。多个要全满足，`晚上|深夜` 是其一就行。认不出的条件在字卡库里会划掉标红。
- 关键词：`{关键词 累 困}` 或 `关键词:累,困`。你说的话里带着其中一个，TA 就优先用这张回；没说到时这张不会出现。

挑字卡的顺序：这个人 × 这个场合 → 这个人的通用字卡 → 谁都能用 × 这个场合 → 谁都能用的通用字卡 → 这个人别的字卡。
同一次回复里不会重复用同一张。

## 概率
字卡库 →「🎲 概率和节奏」里都能改：
- 聊天节奏：回 1~5 条各自的权重（默认 75 / 24 / 1，大多数时候就一句）、你发完多久已读、已读后想多久再回、已读不回的概率
- 聊天里的小动作：夹个表情字卡、顺手发张表情包、引用你说过的话、拍一拍你
- TA 做事：照做的概率、答应邀请/接电话、自主模式里做点什么、多久再想一次
- 氛围：随机来电（每隔多久掷一次、打过来的概率）、TA 某天不记心情的概率、开场动画和格言的开关

- 每个角色单独一套：「概率和节奏」最上面选「只给 某某 单独调」，填了的项只对 TA 生效，空着的跟全局走。

## 语音和图片
- 🎙️ 语音库（字卡库里）：上传 TA 的声音片段，打电话时 TA 说话按概率放这些（可配关键词：说到这个词就放这段）。
- 🖼️ 图片：TA 发图默认从「小功能 → 🖼️ 图库」里按聊的内容挑，不接 API。

## 分享字卡
字卡库上面选好某个角色，点「导出筛出来的」，就是这个人的一整套字卡（带条件、关键词、分组），别人直接导入就能用。

## 小玩法
设置里的「🎲 小玩法」，聊天工具栏里也有一颗 🎲：心情手账（你记一笔，TA 每天也自己记一笔）、今日三张塔罗、雷诺曼、抽签、抛硬币、聊天统计和词云。结果都能一键发到聊天里，TA 会接着回。

## 🤖 自主行动
设置里的「🤖 自主行动」：打开总开关，勾上想让 TA 自己决定的角色。TA 会隔一阵（最快/最慢多久可以调）停下来掷一次骰子——
这次做不做（「做点什么」的概率）、做哪一件（每件事一个权重，数越大越常做，0＝不做）。写日记、发推、写信、发朋友圈、拍你、换状态……做的内容也都从字卡里来。
想马上看效果就点「现在动一下」。

## 和谷雨的关系
- 独立的一套文件，改这里不影响谷雨。
- 存档分开：浏览器里的存储都带 `bailu:` / `bailu_` 前缀，和谷雨同一个浏览器打开也互不干扰；桌面版数据放在 exe 旁边的 `BailuData`。
- 桌面版打包：进 `桌面版` 文件夹，先跑 `npm install`，再双击 `一键打包exe.bat`，出来的是 `白露.exe`。
