# 苹果手机：Scriptable 小组件 + 自己的中转站

苹果不让网页直接放桌面小组件，所以要用免费 App「Scriptable」，数据经过你自己的 Cloudflare 中转站（免费额度足够）。

## 一、搭中转站（只弄一次）

1. 注册 / 登录 Cloudflare → 左边 **Workers 和 Pages** → 创建 → 创建 Worker → 部署。
2. 点「编辑代码」，把 `中转站-worker.js` 整个粘进去替换掉原来的 → 部署。
3. 左边 **存储和数据库 → KV** → 创建一个命名空间（名字随便）。
4. 回到这个 Worker → 设置 → 绑定 → 添加 → KV 命名空间 → **变量名写 `WIDGET`** → 选刚建的那个 → 保存。
5. 浏览器打开 Worker 的网址（https://xxx.workers.dev），看到「谷雨小组件中转站在运行 ✓」就好了。

## 二、谷雨里填好

谷雨 →「📲 手机桌面小组件」→ 同步页：
- 「中转站地址」填 Worker 的网址；
- 「点小组件打开的网址」填你平时打开谷雨网页版的地址；
- 点「现在同步」。

## 三、Scriptable

1. App Store 装「Scriptable」。
2. 谷雨 →「📲 手机桌面小组件」→ 🍎 苹果页 → **复制 Scriptable 脚本**（这里面已经填好地址和口令，比用 `Scriptable脚本-模板.js` 省事）。
3. Scriptable → 右上角 ＋ → 粘贴 → 起个名字。
4. 桌面长按 → 左上角 ＋ → Scriptable → 选大小 → 添加 → 长按小组件 → 编辑小组件 → Script 选刚才那个。
   Parameter 可以写卡片名字（比如「每日一问」），空着就每半小时换一张；大号会一次显示四张。

## 说明

- 苹果的小组件大概 15 分钟以上刷新一次，系统说了算。
- 网页版只有打开着的时候才会同步（切走时也会同步一次）。
- 中转站只存最新的一份卡片文字（30 天不更新自动删），不存聊天记录。口令是谷雨随机生成的，别发给别人。
