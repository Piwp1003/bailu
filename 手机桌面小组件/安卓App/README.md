# 谷雨小组件（安卓桌面小组件 App）

把谷雨 / 白露里的小组件（TA 的心情、每日一问、等级、倒数日、星图……）放到安卓手机的**真桌面**上。
点桌面上的卡片会打开谷雨（或白露），并直接跳到那个功能。

## 一、打包（不用装任何软件，GitHub 帮你打）

1. 登录 GitHub → 右上角 ＋ → New repository → 名字随便（比如 guyu-widget）→ 选 Private 也行 → Create。
2. 新仓库页面点 **uploading an existing file**（或 Add file → Upload files），
   把这个文件夹里的东西拖进去：`app` 文件夹、`build.gradle`、`settings.gradle`、`gradle.properties`、`README.md`
   （`自动打包配置.yml` 不用传）→ Commit changes。
3. 点仓库上方的 **Actions** → 点「set up a workflow yourself」→ 把编辑框里原来的内容删光，
   把 `自动打包配置.yml` 的内容整个粘进去 → 右上角 Commit changes。
   （这一步就是在仓库里建 `.github/workflows/` 下的打包配置，GitHub 看到它就会自动打包。）
   然后再点 **Actions**，会看到「打包谷雨小组件」在转圈，等 3～5 分钟变成绿色对勾。
4. 点进那一次 → 拉到最下面 **Artifacts** → 下载「谷雨小组件-apk」（是个 zip）→ 解压出 `.apk`。
5. 把 apk 传到手机安装（会提示「未知来源」，允许就行）。

以后想重新打包：Actions → 打包谷雨小组件 → Run workflow。签名是固定的，新包可以直接覆盖安装。

## 二、用起来

1. 打开谷雨（安卓 App 版）→ 小程序里找「📲 手机桌面小组件」→ 点「现在同步」。
2. 回手机桌面 → 长按空白处 → 小组件 / 窗口小工具 → 找「谷雨 · 小卡片」→ 拖到桌面。
3. 弹出来的列表里选一张卡片（或者「轮播」，每半小时换一张）。可以放好几个，每个选不同的卡片。
4. 之后谷雨会自动同步（默认每 15 分钟，切到后台时也会同步一次）。

谷雨和白露都装着的话，两边的卡片都会出现在选择列表里。

## 三、说明

- 这个 App 不联网、不要任何权限，只接收谷雨 / 白露发过来的卡片文字。
- 必须是**安卓 App 版**的谷雨 / 白露才能直接发给它；用浏览器打开的网页版发不了（网页版请按「苹果」那套走中转站）。
- 有的手机（小米、华为、OPPO、vivo）会限制后台，如果桌面卡片长时间不更新：
  打开一次谷雨就会刷新；也可以在系统设置里允许谷雨「自启动 / 后台运行」。
